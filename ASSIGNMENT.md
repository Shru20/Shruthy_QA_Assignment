# Backend Test Automation Assignment

We are looking for Automation Engineers who have the mindset that "only the sky is
the limit" and that "automation doesn't stop at testing, it's just a beginning!".

The purpose of this test assignment is to assess your automation skills, allowing
you to demonstrate what you can do and how quickly you can learn.

## Requirements

### Environment & skills

- GitHub account
- Java 17 (JDK)
- Maven 3.6+
- Any IDE you are comfortable with, such as IntelliJ IDEA or VS Code
- Clean Code

### Test Expectations

Develop automated tests that cover the following areas:

- CRUD operations
- Edge cases based on the GitLab Issues API


Use the [GitLab Issues API documentation](https://docs.gitlab.com/ee/api/issues.html)
as the reference for the API under test.

You will need to create an account and an OAuth2 token to complete the assignment.

### Focus Areas

- Do not use a library specifically designed to deal with the GitLab Issues API.
  You are testing the GitLab Issues API itself.
- Include detailed comments or descriptions for every test.
- Include edge cases, boundary conditions, and unusual inputs where relevant.
- Keep the test code clean and maintainable.
- Ensure that the tests are runnable and that the project contains only necessary
  source files.

### Optional Add-ons

- Set up pipeline integration, such as GitHub Actions, to run the tests
  automatically.

### When the Assignment Is Complete

1. Push your solution to GitHub.
2. Set the repository visibility to **public**.
3. Send us the link to your repository.

If you have any questions, please contact us.

This is an open assignment. There is no single right or wrong answer and no end goal
other than demonstrating your automation, pipeline, and coverage skills.

### Time Guidance

We do not expect you to spend weeks or lose sleep over this assignment. Please spend
approximately 6 to 10 hours on it. We want to see how you approach and solve
problems, so feel free to use any automation tool you are comfortable with.

Good luck!
